## Генератор защищенных QR-кодов
**Версия:** 1.0
**Автор:** Разработано для проектов в Липецке (Bitrix/Python)

## Описание
Данная система предназначена для создания QR-кодов, содержимое которых (параметры ссылки) защищено от подделки с помощью криптографической подписи HMAC-SHA256. Это гарантирует, что если злоумышленник изменит данные в ссылке (например, ID баннера или реферальный код), сервер Bitrix отклонит такой запрос как невалидный.

Система состоит из двух частей:
1. **Генератор (Python):** Создает подписанную ссылку и генерирует изображение QR-кода.
2. **Верификатор (PHP/Bitrix):** Проверяет подлинность подписи при переходе пользователя по ссылке.

## Структура файлов
- `index.py` — Скрипт на Python для генерации QR-кодов.
- `bitrix.php` — Обработчик для CMS 1С-Битрикс, проверяющий подпись.
